# 배경음악 올리는 곳

이 폴더에 음악 파일(mp3, m4a, wav, flac 등)을 올리면, 1~2분 뒤 자동으로 웹용 크기(96kbps mp3)로 줄여서
사이트 오른쪽 아래 재생 버튼에 연결됩니다. 원본 파일은 자동으로 지워집니다.

올리는 법: 이 폴더 화면에서 **Add file → Upload files** → 파일을 끌어다 놓기 → **Commit changes**.
(GitHub 웹 업로드는 파일 하나당 25MB까지 됩니다.)

곡 이름은 파일 이름으로 정해지고, 편집기(✎ Write → Background music)의 Title에서 바꿀 수 있습니다.
