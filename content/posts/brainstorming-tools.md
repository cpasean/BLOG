We can find various brainstorming techniques and tools. I would like to share my tools (1) SimpleMind and (2) Ikigai. As introduced in the previous article, our brain recognizes a visual structure intuitively and instantly. We can leverage it with these. SimpleMind is a free mind-mapping app. We can set up various mind maps for individual or team goals with members and set them as a background on our mobile devices. Imagine how awesome it would be if we make a wonderful mind map all together with team members rather than just having verbal brainstorming. Ikigai is multiple composition of Venn diagrams. It's really useful whenever we need to find a core value and each requirement to achieve it.

• SimpleMind: <https://simplemind.eu/>

• Ikigai: <https://positivepsychology.com/ikigai/>
